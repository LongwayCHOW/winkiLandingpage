## 核心素材（请围绕一个"冲突或取舍"展开）

1. **一个真实的技术挑战**：当主题的一个按钮每个在外观、位置、触感、点击反馈都和其他的不同，那我已经经历过测试的时候遭遇太多令人感觉心累疲惫的内存泄露问题，一个个排查真的太花时间了。
2. **你尝试了什么方案**？我尝试了各种各样的画布方案和widget局部刷新和整体刷新方案，非常大的坑在于，你已经开发过2个主题了，在第三、第四个主题时才发现你的技术选项不支持新主题方案的布局不支持/视觉特性/点击特性/阴影裁切/颜色过度生硬/用着用着就崩溃……等等问题
3. **最终怎么解决的**？因为选型造成的连环重构地狱，真是令人感受到烦躁，这种折磨只能在出去爬山和散步之后心情平复时候慢慢用工作量来度过这种艰难的工作时期
4. **一个设计取舍**：没有取舍，只有硬磕
5. **过程中学到的教训**（对同行或用户都有价值的思考）：最好的心情，我已经留给最难的debug和最折磨人的重构了……
