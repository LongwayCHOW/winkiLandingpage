## 基础信息

- **App 名称**：focus one
- **本篇主题**（一个具体的技术/设计话题）：我让我一天中最重要的事情，就常量置顶显示，这样我一拿起手机，就意识到我在破坏掉我做“一天中最重要的事情”这件事的专注度

## 核心素材（请围绕一个"冲突或取舍"展开）

1. **一个真实的技术挑战**：最大的困难来自系统不提供app控制的底层 api让我的app来提供“先完成任务，才显示其他app”的功能
2. **你尝试了什么方案**？最大的失败来自于系统的限制，以及跨平台的系统层面，应该如何提供屏幕常亮显示“今天最重要的一项任务”等内容，并确保在息屏、锁屏、跨设备协作的时候都能提供“快速显示今天任务”的能力，没有这些能力，后续的“事件完成的番茄钟、事件完成的循环次数，本年专注力报告统计”，都无法很好地完成
3. **最终怎么解决的**？目前还没有找到完美解决方案：如何让“今天最重要的一件事”放在手机所有内容展示的最顶层
4. **过程中学到的教训**（对同行或用户都有价值的思考）：保持学习，保持挖掘，随着系统进行迭代
