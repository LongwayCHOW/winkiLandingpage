# 为什么开发deliseek

> **用途**：
我在2025年突然获得了非常严重的心理障碍，每天郁郁寡欢，全身疼痛，什么都不想做。有一天，我不想再这样下去，我没有想说要拯救自己或者怎么样，我只是不想再这下去了，我要改变我的处境。

我慢慢开始痊愈，我开始可以处理一些复杂的工作，一些复杂的文件，然后慢慢地可以开始处理更复杂的流程，我慢慢好起来了……
