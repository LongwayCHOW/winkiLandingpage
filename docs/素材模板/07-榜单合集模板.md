# 07 榜单合集模板（Listicle / Link Bait）

> **用途**：榜单文——「10 个最佳极简 app」这类。**链接诱饵**，最容易被其他网站引用、带来外链。选题要"能引发分享"而非纯推销。
> **对应落地页**：本 app 落地页（你的 app 排在其中）。
> **核心词建议**：`best <类型> 2026`、`<类型> for <人群>`。示例：`best journal app, minimal apps`。
