# 05 教程指南模板（How-To / Tutorial）

> **用途**：教程文——「怎么用 app 解决某问题」「How to start X」。长尾流量主力、易被引用。结构用步骤/清单，让搜索引擎能解析出列表（也为精选摘要做准备）。
> **对应落地页**：本 app 落地页。
> **核心词建议**：`how to <动作>`、`<功能词> for <人群>`。示例：`how to free up iphone storage, delete duplicate photos`。
